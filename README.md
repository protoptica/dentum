# Dentimus: оценка нижней восьмёрки

Интерактивный демонстрационный прототип для загрузки панорамного снимка, выбора зуба 38 или 48 и сравнения прогноза пользователя с имитацией оценки сложности удаления.

Прототип не выполняет медицинский анализ и не является диагнозом или планом лечения.

## Запуск локально

Откройте `index.html` через любой статический HTTP-сервер.
