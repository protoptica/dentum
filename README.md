# Dentimus: оценка нижней восьмёрки

Демо: https://yaroslavnasol.ru/dentum/

Интерактивный демонстрационный прототип для загрузки панорамного снимка, выбора зуба 38 или 48 и сравнения прогноза пользователя с экспериментальной оценкой.

Сразу после загрузки снимка браузерная ONNX-модель `liodon-ai/dental-panoramic-detector` ищет нижние ретинированные зубы. Координаты детекций автоматически перемещают круги 38 и 48 с учётом пропорций и кадрирования изображения. Распределение сложности удаления рассчитывается игровой эвристикой поверх уверенности детектора и не является медицинской вероятностью, диагнозом или планом лечения.

В папке `worker/` находится Cloudflare Worker для второй модели. Он принимает расширенный фрагмент выбранного зуба, вызывает Llama 3.2 Vision, получает категории угла, глубины и отношения к ветви, затем рассчитывает игровое распределение по шкале Pederson. URL опубликованного Worker задан в `config.js`; при ошибке API сайт использует резервную эвристику.

Модель распространяется по лицензии CC BY-NC 4.0 и подходит для некоммерческого демо. Перед коммерческим использованием нужна другая лицензия или собственная модель.

## Запуск локально

Откройте `index.html` через любой статический HTTP-сервер.

Публичная версия размещена в подпапке `dentum/` репозитория `protoptica/dentum.github.io`, поскольку GitHub Pages для этого репозитория отдельно не включён.
